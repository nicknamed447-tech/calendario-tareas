          Sincronización entre dispositivos

          Conecta una base Supabase para guardar el calendario online. Inicia sesión con la misma cuenta en cada dispositivo.

          Sin conectar.
          Configuración necesaria en Supabase
          1. Crea un proyecto en Supabase y copia la URL y la clave publicable desde la configuración de API.
          2. En SQL Editor, pega y ejecuta el SQL siguiente. La tabla limita cada fila a su usuario autenticado.
          3. Usa el mismo proyecto y la misma cuenta en todos tus dispositivos.
          create table if not exists public.agenda_sync (
  user_id uuid primary key references auth.users(id) on delete cascade,
  payload jsonb not null default '{}'::jsonb,
  updated_at timestamptz not null default now()
);
alter table public.agenda_sync enable row level security;
revoke all on table public.agenda_sync from anon, authenticated;
grant select, insert, update on table public.agenda_sync to authenticated;
drop policy if exists "agenda_read_own" on public.agenda_sync;
drop policy if exists "agenda_insert_own" on public.agenda_sync;
drop policy if exists "agenda_update_own" on public.agenda_sync;
create policy "agenda_read_own" on public.agenda_sync for select to authenticated using ((select auth.uid()) = user_id);
create policy "agenda_insert_own" on public.agenda_sync for insert to authenticated with check ((select auth.uid()) = user_id);
create policy "agenda_update_own" on public.agenda_sync for update to authenticated using ((select auth.uid()) = user_id) with check ((select auth.uid()) = user_id);

          No pongas aquí ninguna clave service_role. La clave publicable está pensada para el navegador; el acceso a tus datos se restringe con inicio de sesión y RLS.
